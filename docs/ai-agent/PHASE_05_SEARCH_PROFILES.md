# PHASE 5 — SEARCH, FILTERING & PROFILE MANAGEMENT

## Objective

Implement powerful job discovery and complete profile management.

## Job Search

Implement backend search/filtering by:

* keyword
* category
* location
* salary
* experience
* job type
* remote
* company

Implement sorting:

* latest
* highest salary
* deadline
* popular

Support:

* pagination
* query parameters
* efficient database queries
* appropriate indexes

Do not fetch the entire jobs collection and filter it in the frontend.

## Frontend Search

Build:

* search bar
* filter panel
* sorting controls
* result count
* pagination
* mobile-friendly filter UI
* clear filters

URL query parameters should represent search state where appropriate.
